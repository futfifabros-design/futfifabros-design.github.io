GTA6 Clipbot

Last updated: November 19, 2026

GTA6 Clipbot is a private, single-user tool. It edits short gameplay clips from livestreams that are part of clipping campaigns the operator has joined, and posts them to the operator's own TikTok account through TikTok's official Content Posting API. It is not offered to the public and has no other users.

  1. Use. The tool is used only by its operator to publish content to the operator's own TikTok account. No other person can sign up or use it.

Privacy Policy

  • What data is used. When the operator connects their TikTok account, TikTok returns an access token, a refresh token and basic profile information (open ID, display name, avatar). The tool uses these only to post videos to that account and to check the posting status.
  • Where it is stored. Tokens are stored only on the operator's own computer, in a file readable only by that user. Nothing is sent to any server other than TikTok's official API.
  • No third parties. No data is sold, shared or used for advertising or analytics.
  • Other people's data. The tool does not collect data about TikTok users or viewers.
  • Deletion. The operator can revoke access at any time in the TikTok app (Settings → Security → Apps and services) and delete the local token file.
